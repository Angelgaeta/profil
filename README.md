## 🧭 Principes d’architecture (ma manière de travailler)

- **Responsabilités claires** : séparation des couches, contrôleurs minces, logique métier au bon endroit  
- **API = source de vérité** : validation/autorisation côté serveur, erreurs cohérentes (401/403/422)  
- **Lisibilité > complexité** : nommage, découpage, code review-friendly  
- **Qualité continue** : tests unitaires ciblés, refacto progressive, dette maîtrisée  
- **UX pragmatique** : parcours simples, états d’erreur clairs, accessibilité prise en compte
